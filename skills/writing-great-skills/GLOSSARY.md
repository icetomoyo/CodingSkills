# 术语表 — 写好 skill

构成"什么是好 skill"的领域模型。skill 的存在,是为了从一个随机性系统中逼出确定性;根原则是**可预测性(Predictability)**,下面每个术语都是作用于它的杠杆。这是 [`writing-great-skills`](SKILL.md) 的披露参考。

术语按轴分组:**调用方式(Invocation)**(skill 如何被触达)、**信息层级(Information Hierarchy)**(内容如何排布)、**引导(Steering)**(agent 运行时行为如何被塑造)、**精修(Pruning)**(如何保持精简)。每个**失败模式(failure mode)**紧挨治愈它的杠杆,标注 _失败模式_。

任一定义中的**加粗术语**本身也在本表中有定义,按标题查找。

## 可预测性(Predictability)

skill 让 agent 每次运行以相同*方式*行为的程度——相同的过程,而非相同的输出(一个头脑风暴 skill 应当*可预测地*发散;它的 token 变,行为不变)。所有其他术语服务的根原则——成本和可维护性是它的症状,不是对手。

_避免_:consistency、reliability、robustness、output-determinism、一致性、可靠性

## 调用方式(Invocation)

skill 如何被触达——以及你为这个选择付出的两种负载。

### 模型调用(Model-Invoked)

保留 **description(描述)** 字段的 skill,agent 能看到它并自主触发——而人仍可键入其名,所以模型调用始终*包含*用户触达。不存在"仅模型"状态:描述只*添加* agent 发现,从不移除人的触达。每个 turn 付出永久的**上下文负载(context load)**换取这种可发现性。可被其他 skill 触达,因为让 skill 可被 agent 发现的描述也让它可被调用。一个内容全是**参考(reference)**的模型调用 skill 也是共享参考的一处归宿:其他 skill 能调用它,所以多个 skill 需要的参考住在一处。仅当 agent 必须自主触达时才选模型调用;若它除手动外从不触发,删掉描述,不付上下文负载。

_避免_:ability、tool、capability、能力、工具

### 用户调用(User-Invoked)

**description(描述)** 被剥离的 skill——对 agent 不可见,只有人键入其名才能触达(仅用户,而**模型调用**是用户*且* agent)。以 agent 可发现性换零**上下文负载**。因它没有描述,除人之外什么都触达不了它:没有其他 skill 能触发它。

_避免_:procedure、workflow、command、流程、工作流、命令

### 描述(Description)

skill 的机器可读触发器,也是**模型调用** skill 被迫始终加载的唯一**上下文指针(context pointer)**。它的存在本身*就是*调用轴:保留它,skill 就是模型调用(且可被其他 skill 触达);删掉它,skill 就是**用户调用**,仅人能触达。模型调用 skill **上下文负载**的来源。

_避免_:frontmatter、summary、前言、摘要

### 上下文指针(Context Pointer)

agent 上下文中持有的、点名某些上下文外材料并编码触达条件的引用。**描述**是顶层上下文指针(上下文窗口 → skill);指向披露文件的指针是低一层的同一物件。它的*措辞*——而非目标——决定 agent *何时*触达、*多可靠*地触达。一个必有目标背后是措辞孱弱的指针,是方差 bug:先修措辞,仅在磨利失败时才内联材料。

_避免_:link、reference、import、链接、引用

### 上下文负载(Context Load)

**模型调用** skill 强加给 agent 上下文窗口的代价——它的**描述**始终加载,既耗 token 又耗注意力。**用户调用** skill 因无描述而逃避的代价,也是拆分出更多模型调用 skill 的刹车。

_避免_:token cost、context bloat、token 开销、上下文膨胀

### 认知负载(Cognitive Load)

**用户调用** skill 强加给人的代价——人必须记在脑中的东西:哪些 skill 存在、何时触达各自(人就是索引)。**模型调用**因 agent 可发现而移除的代价,也是拆分出更多用户调用 skill 的刹车。这不是该最小化的代价:它是人类能动性的价格,是某些 skill 保持用户调用的理由。在人类判断要紧处花它;在不要紧处移除它。

_避免_:human index、burden、overhead、人类索引、负担

### 路由 skill(Router Skill)

一个**用户调用** skill,职责是指向你其他用户调用 skill——点名各自及何时触达——让人只记一个 skill 而非许多个。它只能提示,永远不能触发它们:用户调用 skill 没有**描述**,所以除人之外什么都触达不了。当用户调用 skill 增殖时**认知负载**的解药。

_避免_:dispatcher、menu、registry、index、调度器、菜单、注册表

### 粒度(Granularity)

你划分 skill 的精细程度。更细的划分付出两种负载之一:更多**模型调用** skill 付出**上下文负载**(更多描述挤占窗口、争夺注意力);更多**用户调用** skill 付出**认知负载**(人要记更多、触达更多)。两种切法指导划分。按**调用**,当你有独立**锚词(leading word)**该触发它——一个你在 prompt 中实际使用的触发词——时切出模型调用 skill。按**序列**,当一个步骤的**完成后步骤(post-completion steps)**需要隐藏时切分一串**步骤(steps)**,因为把它隔到自己的上下文中清除其后继。当心反向操作:合并序列会把每个步骤的完成后步骤暴露给后继,招致过早完成。

_避免_:chunking、modularity、分块、模块化

## 信息层级(Information Hierarchy)

skill 内容如何排布,以及每块落在阶梯的哪一档。

### 信息层级(Information Hierarchy)

skill 内容按 agent 需要的紧迫程度排序——一条阶梯,由两刀产生:文件内还是指针背后,步骤还是参考。各档:

- **步骤(Steps)**——文件内,主层
- **参考(Reference)**,文件内——次层
- **参考**,披露——在**上下文指针**背后

没有**步骤**的 skill 只用下两档——常是合法的扁平同级集合(如一次评审的每条规则在同一档),好安排,不是坏味道。层级独立于调用:skill 可模型或用户调用,不论全是步骤、全是参考、或兼有。当 skill 有步骤时,本该披露的文件内参考会埋没它们,让关注它们变成抛硬币——一个方差杠杆,不仅是可读性杠杆。保持阶梯顶层可读;能推下的尽量推下。

_避免_:structure、organization、layout、结构、组织

### 步骤(Steps)

agent 执行的有序动作——skill 有它们时,内容的主层,也是在 `SKILL.md` 中挣得位置的部分。并非每个 skill 都有步骤:skill 可全是步骤(`tdd`)、全是**参考**(一次评审)、或兼有,独立于调用。每个步骤以**完成判据(completion criterion)**收尾,清晰或模糊。

_避免_:workflow、instructions、choreography、工作流、指令

### 参考(Reference)

agent 按需查阅的材料——定义、事实、参数、示例、条件指令。当 skill 有**步骤**时它次之;当 skill 无步骤时它是全部内容;或它住在任何 skill 之外——见**外部参考**。经**上下文指针**触达,是**渐进披露**的首要候选。

_避免_:supporting material、docs、background、支撑材料、文档

### 外部参考(External Reference)

住在 skill 系统之外的**参考**——一个普通文件,无**描述**、无**步骤**、不可调用——任何 skill 都可指向。无需自己触发的共享参考的归宿,也是两个**用户调用** skill 能用的唯一共享归宿,因为两者都没有描述,谁也触发不了谁。

_避免_:doc、resource、knowledge base、文档、资源、知识库

### 渐进披露(Progressive Disclosure)

把**参考**沿阶梯下移——从 `SKILL.md` 推到**上下文指针**背后——让顶层保持可读。主要不是 token 优化;它是保护**信息层级**的方式。由**分支(branching)**授权:披露只有某些分支需要的,内联每条路径都需要的;若指针在必有材料上触发不可靠,磨利其措辞,仅在失败时拉回内联。

_避免_:lazy loading、chunking、懒加载、分块

### 就近聚合(Co-location)

把 agent 一次需要的材料放在一处——一个概念的定义、规则和注意事项归在同一标题下,而非散落文件各处——让读一处带出它的邻居。**信息层级**的文件内同伴:层级排序一块内容*落多深*;就近聚合决定它*落定后旁边放什么*。一坨**参考**该用什么格式没有公式;测试是 skill 读起来该像为 agent 写的文档,而聚合的材料读起来像,散落的材料不像。区别于**重复(duplication)**:后者在两处重复同一含义,而散落是把一个含义碎片化到多处。

_避免_:grouping、clustering、cohesion、分组、聚类、内聚

### 蔓生(Sprawl)

_失败模式_。skill 单纯太长——`SKILL.md` 中行太多——独立于它们是否过时或重复。即使全是鲜活、全唯一的 skill 也会蔓生。它损害可读性(agent 在能行动前要涉过更多,注意力在盈余上变薄)、可维护性(每多一行就多一行要保持**相关(relevance)**)和 token。解药是**信息层级**:把**参考**推到**上下文指针**背后,按**分支**或序列拆分,让每条路径只带它需要的。区别于**沉淀**(过时累积导致的长度)和**重复**(重复含义导致的长度)——蔓生是长度本身,不论原因。

_避免_:bloat、length、size、verbosity、膨胀、长度、冗长

## 引导(Steering)

塑造 agent 运行时行为走向**可预测性**的杠杆。

### 分支(Branch)

skill 被调用的不同方式——skill 处理的一种情形——不同运行走其不同路径。步骤多的 skill 可能带许多分支;线性的没有。

_避免_:path、case、fork、路径、情形、分叉

### 锚词(Leading Word)

一个已活在模型预训练中的紧凑概念——又称 _Leitwort_——agent 运行 skill 时用它来思考。它以最少 token 编码一条行为原则,靠招募模型已有的先验(如 *lesson*、*最近发展区*、*fog of war(战争迷雾)*、*tracer bullet(曳光弹)*)。作为 token 重复,从不作为句子,它在 skill 中积累出分布式定义,锚定一整片行为。自造词若定义清晰也能用,但造词招募不到先验——你在定义 token 上花的,是预训练词免费给的。先找已有的词。

锚词两度服务**可预测性**。在正文中锚定**执行(execution)**——每次概念出现,agent 都触达同一行为;在扁平参考中它把注意力聚焦到一类该找的东西上,每次运行招募正确的检查。在**描述**中锚定**调用(invocation)**——不仅限 skill 内:当同一个词活在你的 prompt、文档和代码库中,agent 把这套共享语言链到 skill,更可靠地触发。用你实际想触发 skill 时使用的锚词来措辞描述。

_避免_:keyword、term、motif、关键词、术语、母题

### 完成判据(Completion Criterion)

告诉 agent 一个工作单元完成与否的条件——它据此判断的目标。两个属性让它成为杠杆而非仅是品质。其**清晰度(clarity)**(agent 能区分完成与未完成?)抵抗**过早完成**——模糊的边界("理解达成")让 agent 宣布完成、滑到下一步;这根轴需要*步骤*才咬得住,因为过早完成是步骤间的失败。其**要求度(demand)**(它要求多少)设定**腿活(legwork)**——"每个改动的 model 都被清点"逼出充分工作,而"产出一份变更清单"不会——这根轴*不*受步骤绑定:它能约束一坨扁平参考,这就是无步骤的 skill 仍带穷尽性门槛("每条规则都用到")的方式。最强的判据既可核对又穷尽。

_避免_:done condition、exit condition、stopping rule、完成条件、退出条件、停止规则

### 腿活(Legwork)

agent 在单个步骤内幕后做的工作——读文件、探查代码库、做改动、挖出它需要的而非推给用户。它住在步骤结构之下:从不写成自己的步骤,潜伏在措辞中,由 agent 而非 skill 控制。**完成后步骤**跨步拉力的步内对应物。由**锚词**(*comprehensive*、*thorough*)或要求工作穷尽的**完成判据**抬升——包括作用于扁平参考的要求轴,正是它驱动扁平参考的 skill 覆盖其所有档。当要求缺失或**过早完成**截短步骤时,腿活变薄。

_避免_:scope、effort、diligence、coverage、范围、努力、勤勉、覆盖

### 完成后步骤(Post-Completion Steps)

当前步骤之后的**步骤**。可见时,它们把 agent 向前拉向**过早完成**——看到越多,拉力越强;防御是通过把步骤序列拆二来隐藏它们。

_避免_:horizon、fog of war、lookahead、地平线、前瞻

### 过早完成(Premature Completion)

_失败模式_。当前步骤未真正完成就结束,因为 agent 的注意力滑向"完成"而非工作。一种步骤间失败:它需要**步骤**才发生——无步骤的 skill 提早退出不是过早完成,而是要求未满下薄薄的**腿活**。两股力量的拔河:可见的**完成后步骤**(向前拉)和**完成判据**的清晰度(阻力——锋利、可核对的门槛撑得住;模糊的让步)。模糊是必要条件:锋利的边界不管后继步骤多可见都撑得住,所以从不抢跑的步骤无需防御。两个杠杆撑住会抢跑的步骤,但按序出手:**先磨利边界**——它局部且便宜。仅当判据无法更清晰*且*你确实观察到抢跑时才**隐藏后继步骤**——而隐藏只在真实上下文边界(用户调用交接或子 agent 派发;内联模型调用把后继步骤留在上下文中,什么也没清除)上有效。薄腿活的一个原因,但区别于它:腿活可在步骤跑到完成时仍薄。

_避免_:premature closure、the rush、rushing、shortcutting、过早闭合、抢跑

### 否定(Negation)

_失败模式_。用禁止来转向——告诉 agent *不要*做什么——把被禁行为拖进上下文,让它*更*可及,而非更不可及。_别想大象_,大象就是全部;_永远别写冗长注释_,冗长就是 agent 刚读到的模式。否定是一个弱修饰符,被强激活的概念碾过,所以禁令半读起来像做那件事的指令。它的**锚词**是*大象*:禁止命名进画框的任何东西。解药:提示**正面**——描述目标行为("写单行注释")让被禁的永不出口。禁止仅在无法正面表述的硬护栏上挣得位置;即便如此也配上正面目标,让注意力落在该做什么上。

_避免_:ironic rebound、don't-prompting、the pink elephant、反讽反弹、粉红大象

## 精修(Pruning)

保持 skill 精简——每个解药配对它治愈的失败。

### 单一事实源(Single Source of Truth)

每个含义恰好住在一个权威位置的理想状态,使改 skill 行为是改一处。**重复(duplication)**是对它的违反。

_避免_:home、canonical location、归宿、规范位置

### 重复(Duplication)

_失败模式_。同一含义被给了不止一个**单一事实源**。它耗费维护(改一处,必须改其余)、耗费 token,并膨胀权重——重复一个含义在阶梯上把它抬到超出其真实排序。**锚词**的意外反面:锚词靠重复一个 token 故意抬升注意力,从不重复含义。

_避免_:repetition、redundancy、重复、冗余

### 相关性(Relevance)

一行是否仍关系到 skill 做的事——保留什么的透镜。一行失去相关性,要么因从不关系任务(纯解说,或该披露的**分支**),要么因过时:随着它描述的行为或世界变化而漂移失修。更短的 skill 更易保持相关,因为每行更便宜检查。区别于**空操作(no-op)**:相关性问一行是否关系任务,而非是否改变行为。

_避免_:load-bearing、staleness、freshness、承重、过时、新鲜度

### 沉淀(Sediment)

_失败模式_。沉在 skill 中永不清除的旧内容层,因为添加感觉安全、移除感觉危险——于是过时和无关的行累积,你得钻透它们才找到仍鲜活的。任何缺乏精修纪律的 skill 的默认命运;**相关性**的缓慢侵蚀,区别于**重复**的重复含义。

_避免_:accretion、bloat、cruft、rot、堆积、膨胀、腐朽

### 空操作(No-Op)

_失败模式_。因模型默认就会做而什么都不改的指令——你付负载告诉 agent 它本就会做的事。测试:一行相对默认改变了行为吗?一行可以完全**相关**却仍是 no-op。让**锚词**免费的同样先验让 no-op 一文不值。

锚词是*技术*;空操作是对一行的*裁决*——两者交叉。太弱打不过默认的锚词是 no-op(_be thorough_ 而 agent 本来就差不多 thorough),解药是通过裁决的更强词(_relentless_),不是换技术。所以 no-op 测试——它相对默认改变行为了吗?——也是你给锚词的重复打分的方式。这是模型相对的,非读者相对的:两人争论一行是否 no-op,争论的是默认,靠运行 skill 而非辩论来裁决。

_避免_:redundant instruction、restating the obvious、belaboring、冗余指令、重述显而易见
